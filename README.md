# LifeOS Harmony

Build a complete production-quality React + TypeScript frontend redesign for LifeOS exactly as specified. This is a frontend-only redesign for an existing backend/API: preserve backend-agnostic architecture, typed models, centralized API layer/adapters, mock demo data separated from components, and do not invent backend contracts. Create the dark-mode-first responsive personal operating system with the specified palette and visual tone. Prioritize Today, Habits + Habit Detail, Dashboard/Insights, and Weekly Review, then include Goals, Calendar, Settings, minimalist auth states, Cmd/Ctrl+K command palette, sidebar/mobile navigation, and all listed functional frontend interactions. Use reusable components/design tokens, polished accessible charts with tooltips/textual summaries and realistic irregular sample data, plus loading/empty/error/partial/auth/network states. Implement the routes and desktop/mobile experience; no generic SaaS look, gamification, excessive cards, glow, gradients, or neon.
